# Silo & SlyGuy Search

Kodi context-item add-on for searching a PVR recording across Silo and installed SlyGuy video add-ons.

The Silo search provider uses the current KOLO Kodi add-on ID, `plugin.video.kolo`, and its existing search route. Results are displayed as **[Silo]** in Kodi. SlyGuy results retain their original plugin URLs and provider labels.

Requirements:
- Kodi Matrix or newer
- KOLO (`plugin.video.kolo`) installed for Silo Server results
- SlyGuy video add-ons installed for SlyGuy results

No third-party Python modules are required.
