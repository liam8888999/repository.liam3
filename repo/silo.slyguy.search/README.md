# Silo & SlyGuy Search

Kodi context-item add-on for searching a PVR recording across Silo and installed SlyGuy video add-ons.

The add-on uses Silo's existing Kodi search route and SlyGuy's standard search route, retaining the original plugin URLs returned by each source.

Requirements:
- Kodi Matrix or newer
- Silo installed for Silo results
- SlyGuy video add-ons installed for SlyGuy results

No third-party Python modules are required.
